# 🧪 Retours testeurs + lancement Instagram — SubPilot

## 1. Formulaire de retour (Google Forms) — questions clé en main

> Crée un formulaire sur **forms.google.com** → colle ces questions.
> Titre suggéré : **« SubPilot — ton avis de testeur (2 min) »**
> Description : *« Merci de tester SubPilot ! L'app est en version test : tes retours servent directement à l'améliorer. 🙏 »*

1. **Sur quel appareil utilises-tu SubPilot ?** *(choix unique)*
   - iPhone (installé sur l'écran d'accueil)
   - iPhone (dans Safari, non installé)
   - Android (installé)
   - Android (dans le navigateur)
   - Ordinateur

2. **Note globale** *(échelle 1 à 5 ⭐)*

3. **Facilité d'utilisation** *(échelle 1 à 5)*

4. **Quelle fonctionnalité t'a le plus convaincu ?** *(choix unique)*
   - Import automatique depuis un e-mail
   - Rappels avant prélèvement
   - Aide à la résiliation
   - Vue budget / tableau de bord
   - Mode sombre

5. **Une fonctionnalité qui manque ou à améliorer ?** *(réponse longue)*

6. **As-tu rencontré un bug ? Décris-le (+ ton appareil).** *(réponse longue)*

7. **Recommanderais-tu SubPilot à un ami ?** *(échelle 0 à 10)* — (mesure le "NPS")

8. **Serais-tu prêt·e à payer UNE fois pour débloquer l'illimité ? Quel prix te semble juste ?** *(choix unique)*
   - Non, seulement si gratuit
   - 2,99 €
   - 4,99 €
   - 6,99 €
   - Plus

9. **Comment as-tu connu SubPilot ?** *(choix unique)*
   - Instagram
   - TikTok
   - Un ami
   - Reddit / forum
   - Autre

10. **(Optionnel) Laisse ton e-mail** si tu veux le 🎁 Premium à vie offert aux 100 premiers testeurs, ou être recontacté. *(réponse courte)*

**Réglages utiles :** active « Limiter à 1 réponse » = NON (pas de connexion obligatoire), et coche « Recueillir les adresses e-mail » = NON (déjà en Q10, optionnel).

## 4. Quand la phase de test sera finie — la suite

1. **Analyse les retours** (le formulaire te donne les graphiques) :
   - Note moyenne + NPS → est-ce que les gens aiment ?
   - Fonctionnalité préférée → ta force, à mettre en avant.
   - Prix accepté → ton futur modèle (gratuit + option payante).
2. **Priorise** : corrige d'abord les **bugs bloquants**, puis les 2-3 **demandes qui reviennent le plus**. Ignore le reste pour l'instant.
3. **Décide du modèle** : garde le cœur gratuit, ajoute une option payante unique (le formulaire te dit quel prix).
4. **Vrai lancement** : quand l'app est stable et validée →
   - **Product Hunt** (lancement makers),
   - vidéos TikTok/Reels régulières,
   - éventuellement une vraie page de présentation.
5. **Preuve sociale** : réutilise les meilleurs retours (captures d'écran) dans tes posts.
