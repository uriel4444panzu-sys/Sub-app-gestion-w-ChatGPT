# Visuels promotionnels SubPilot

4 visuels au format portrait **1080 × 1920** (vectoriels, donc nets à toute taille) :

| Fichier | Met en avant |
|---|---|
| `01-apercu.svg` | Vue d'ensemble : suivi des abonnements + total mensuel |
| `02-import.svg` | Import intelligent : coller un e-mail → détection auto |
| `03-rappels.svg` | Rappels automatiques avant chaque renouvellement |
| `04-resiliation.svg` | Aide à la résiliation en 1 clic |

## Prévisualiser
Ouvre `promo/index.html` dans un navigateur : les 4 visuels s'affichent côte à côte.

## Exporter en PNG (pour ton annonce / les réseaux)
- **Le plus simple** : ouvre un `.svg` directement dans Chrome → il s'affiche en plein écran, net → capture d'écran.
- **Ou** : convertisseur en ligne « SVG to PNG » (cloudconvert, svgtopng.com…).
- Les SVG sont vectoriels : aucune perte de qualité, quelle que soit la taille.
