Avant de commencer

Installez SubPilot sur votre écran d'accueil

Ça prend 20 secondes. Ensuite, SubPilot s'ouvre comme une vraie application, en plein écran, depuis son icône.

Ouvrez d'abord ce lien dans votre navigateur

Vous êtes dans une application (Instagram, TikTok…) : l'installation y est impossible.

Lien copié ✓ Collez-le dans la barre d'adresse de votre navigateur.

⚠️ Étape indispensable

Utilisée dans le navigateur, SubPilot ne donne pas accès à toutes ses fonctionnalités : vous ne recevrez notamment aucune notification avant vos prélèvements. Pour en profiter pleinement, ajoutez-la à votre écran d'accueil.

💻 Vous êtes sur ordinateur ? SubPilot est pensée pour le téléphone : ouvrez ce lien sur votre smartphone pour l'installer.

  1. Ouvrez ce lien dans Safari.
  2. Touchez le bouton Partager . Sur les iPhone récents, il se trouve dans le menu ••• en bas de l'écran.
  3. Faites défiler, puis touchez « Sur l'écran d'accueil » .
  4. Touchez Ajouter, en haut à droite.
  5. Ouvrez SubPilot depuis sa nouvelle icône, connectez-vous, puis activez les notifications dans Compte.

Vous utilisez Chrome ou Firefox sur iPhone : l'ajout passe aussi par le bouton Partager, mais Safari reste le plus fiable.

Sur iPhone, les notifications fonctionnent uniquement si SubPilot est ajoutée à l'écran d'accueil.

Ou, manuellement :

  1. Ouvrez ce lien dans Chrome.
  2. Touchez le menu , en haut à droite.
  3. Touchez « Ajouter à l'écran d'accueil » (ou « Installer l'application »), puis Installer.
  4. Ouvrez SubPilot depuis sa nouvelle icône, connectez-vous, puis activez les notifications dans Compte.

Avec Samsung Internet : menu ≡, puis « Ajouter la page à » → « Écran d'accueil ».

✅ SubPilot est installée ! Ouvrez-la maintenant depuis son icône sur votre écran d'accueil.

Fonctionnalités limitées : pas de notifications.
